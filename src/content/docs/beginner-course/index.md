## 你适不适合这条路线

这条路线适合：

- 刚开始学习测试开发，不知道怎么入门
- 功能测试想转测开，但不会写代码
- 学过一些零散知识，但不会串成项目

如果你已经能独立设计测试框架，可以直接去[技术专题](/testdev-interview-site/tech/)或[面试追问链](/testdev-interview-site/interview-chains/)。

## 学完后的最小能力清单

完成这条路线后，你应该能：

- 用 3 句话解释测试开发岗位的职责
- 读懂 Python 测试代码中的函数、列表、字典和断言
- 用 Pytest 写一个接口测试，断言状态码和响应体
- 完成一个登录接口的自动化测试小项目
- 用 2 分钟向面试官介绍这个项目
